# SYRYX

Official website for SYRYX, a music project shaped by rock, creativity, and a distinct visual identity. Explore the project, read song lyrics, and find links to listen to the music.

## Website

The site includes:

- **Home:** introduction to SYRYX.
- **About:** information about the project and its sound.
- **Songs:** a collection of lyrics with an interactive viewer.
- **Listen:** links to SYRYX on Spotify, Apple Music, and YouTube Music.

## Built with

- HTML
- CSS
- JavaScript

## Project structure

```text
.
├── index.html             # Redirects to the main page
├── HTML/                  # Website pages
├── STYLES/                # CSS styles
├── REQUIREMENTS/          # JavaScript files and Render configuration
├── LYRICS/                # Song lyrics
└── images/                # Website images
```

## Run locally

Clone the repository and open `index.html` in a web browser:

```bash
git clone https://github.com/Antonio-garcia-2025/syryx_page.git
cd syryx_page
```

You can also open `HTML/index.html` directly.

Share link deploy: https://syryx-page.onrender.com


The repository includes a Render configuration for a static website. To deploy, create a **Static Site** in Render connected to this repository. The site does not require a build command; publish the repository root.

The root `index.html` automatically redirects visitors to the main page in `HTML/index.html`.
